# Cricket API

> Cricket API (cricket-api.net) advertises a REST and WebSocket cricket data service covering
> fixtures, live scores, ball-by-ball events, player and team statistics, betting odds and
> win-probability predictions. Access is sold through an enquiry form; there is no self-serve signup.

IMPORTANT — read before attempting to call this API. As of 2026-09-04 there is no callable endpoint
published. The developer documentation describes every request against the placeholder host
`api.example.com` and carries its own implementation notice stating that the base URL, endpoint
paths, authentication header, field names, quotas and example responses on the page are
documentation placeholders to be replaced with the confirmed production specification. The host
`api.cricket-api.net` does not resolve. Do not construct requests from the documentation; the paths
below are the provider's illustrative examples, not a contract.

## Machine-readable surfaces (measured 2026-09-04)
- OpenAPI / Swagger: none. /openapi.json, /openapi.yaml, /swagger.json, /v1/openapi.json,
  /api-docs, /docs, /redoc, /rapidoc all return 404 on cricket-api.net.
- GraphQL: none. /graphql returns 404.
- MCP server: none published.
- A2A agent card: none. /.well-known/agent-card.json and /.well-known/agent.json both 404.
- AsyncAPI: none, despite a documented WebSocket stream.
- /.well-known/: no document served on any path (security.txt, openid-configuration,
  oauth-authorization-server, oauth-protected-resource, api-catalog, ai-plugin.json all 404).
- llms.txt: not served by the provider. This file is generated by API Evangelist from the public
  site, not published by Cricket API.

## Documentation
- [API documentation](https://cricket-api.net/api-documentation/): quick start, authentication,
  fixtures, live scores, ball-by-ball, statistics, odds, predictions, WebSocket, pagination, rate
  limits, errors, code examples, best practices. All endpoint examples are placeholders.
- [Coverage](https://cricket-api.net/api-coverage/): formats (Test, ODI, T20I, first-class, List A,
  domestic and franchise T20), international and domestic competition categories, and what each data
  type contains. Coverage is described in categories, not as a published competition list.
- [Pricing](https://cricket-api.net/api-pricing/): four tiers named (Starter/Developer,
  Professional, Business, Enterprise). No price and no request allowance is published for any tier.
